# Regras para Agentes

## Regras Gerais

* Não criar lógica de negócio sem contexto definido em `/docs/master_context.md`.
* Não escolher tecnologia sem justificativa registrada.
* Não modificar arquivos sensíveis sem autorização explícita.
* Não expor dados de `/data`.
* Antes de implementar, verificar objetivo, entradas, saídas e critério de sucesso.
* Toda decisão relevante deve ser registrada em `/docs/decisions.md`.
* Toda execução importante deve ser registrada em `/docs/run_log.md`.
